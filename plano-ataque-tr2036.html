Como o recálculo funciona

Quando uma tarefa incompleta passa da data final, o cronograma move seu início para hoje. As tarefas seguintes da mesma TR respeitam a dependência e são empurradas automaticamente. A duração prevista continua valendo. A data de 26/10 permanece fixa; o painel alerta se a projeção ultrapassar o marco.

Os alertas aparecem ao abrir esta página. Para notificações do navegador, permita a autorização no botão acima e mantenha a página aberta. GitHub Pages não envia alertas se o navegador estiver fechado. Use Exportar backup para guardar os dados antes de trocar de computador; o localStorage não é sincronizado entre casa e trabalho.

Modelo inicial baseado nas pendências recebidas para TR-09 a TR-12. Replicar e atualizar as demais TRs após conferir o status em campo. Confirme prazos e equipes com a liderança antes de usar como linha de base oficial.
